# fagrapport115_Bear_NOR_2016-2025

Repository containing the input data, R script, figures, tables and raster density maps from the following technical report:

Dupont, P., Hansen, N.R., Milleret, C., Semper-Pascual, A., Brøseth, H., Kopatz, A., Kindberg, J., and Bischof, R., 2026. **Estimates of brown bear density, abundance, and population dynamics in Norway 2016 - 2025** - MINA fagrapport 115. 35 pp. [PDF LINK](https://www.researchgate.net/publication/414083092_Estimates_of_brown_bear_density_abundance_and_population_dynamics_in_Norway_2016_-2025)
