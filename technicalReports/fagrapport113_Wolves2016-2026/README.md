# fagrapport113_Wolves2016-2026

Repository containing the input data, R script, figures, tables and raster density maps from the following technical report: 
Dupont, P., Milleret, C., Semper-Pascual, A., Brøseth, H., Flagstad, Ø., Kindberg, J., Svensson,L., and Bischof, R., 2026. Estimates of wolf density, abundance, and population dynamics in
Sweden and Norway, 2016–2026 - MINA fagrapport 113. 36 pp. [PDF LINK](https://www.researchgate.net/publication/392551288_Estimates_of_wolf_density_abundance_and_population_dynamics_in_Scandinavia_2016-2026)
