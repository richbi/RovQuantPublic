# fagrapport117\_WolverineSweden\_2026

Repository containing the input data, R script, figures, table and raster density map from the following technical report:
Semper-Pascual, A., Milleret, C., Dupont, P., Hedmark, E., Spong, G., Königsson, H., and Bischof, R., 2026. Preliminary estimates of wolverine density and abundance in Sweden, 2025/2026 - MINA fagrapport 117. 17 pp.. [PDF LINK](https://static02.nmbu.no/mina/publikasjoner/mina_fagrapport/pdf/mif106.pdf)
